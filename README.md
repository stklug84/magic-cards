# Inventory Ontologies

This repository contains the existing Ontologies that will be used to create an inventory of books, computer games, and magic cards.

## Existing Ontologies

- **Books**: [`BooksOntology.ttl`](./BooksOntology.ttl)
- **Computer Games**: [`ComputerGamesOntology.ttl`](./ComputerGamesOntology.ttl)
- **Magic Cards**: [`MagicCardsOntology.ttl`](./MagicCardsOntology.ttl)
